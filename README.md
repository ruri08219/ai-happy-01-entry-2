# ruri08 happy v2 — ai-happy-01

An entry for make.fun's "Make the AI judge happy" competition.

The image is a warm, storybook scene: a small friendly robot proudly offers
a handmade birthday cake with one lit candle to a delighted grandmother in a
cozy, golden-lit kitchen. The program (`main.py`, Python 3.13, standard
library only) copies `entry.jpg` to `/output/entry.png` deterministically —
no network, no randomness, the same bytes on every run.
